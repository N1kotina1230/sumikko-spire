# 角落尖塔 · Sumikko Spire

和《角落生物》的炸虾尾（えびふらいのしっぽ / Ebifurai no Shippo）一起，从森林角落走到云朵塔顶。一个使用 React 19、TypeScript、Vite 6 编写的可玩网页卡牌 Roguelike 原型。

## 启动

需要 Node.js 20.19+（推荐 22 LTS）和 npm。

```bash
npm install
npm run dev
```

在浏览器打开终端打印的本地地址。生产构建：

```bash
npm run build
npm run preview
```

`dist/` 可以部署到普通静态网站服务器，无需后端或 API 密钥。应用不依赖外部图片、字体或音频服务。

## 免费发布到互联网

项目已提供 GitHub Pages 自动部署工作流。第一次启用 Pages 和后续提交修改的详细中文步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。朋友直接打开网页即可玩，无需安装。

## 操作

- 初始生命 60，每回合 3 点能量、抽 5 张牌，手牌上限 10 张。
- 点击卡牌立即使用。多个敌人时，先点击敌人选定目标；未手动选中时默认攻击第一个存活敌人。
- 点击「结束回合」弃掉剩余手牌并结算敌人行动。敌人头顶显示下一步意图。
- 格挡抵消伤害，在玩家下个回合开始时清空；抽牌堆空时将弃牌堆洗回。
- 勇气增加每次攻击的伤害；受潮使受到的攻击伤害增加 50%；发霉在敌人行动前扣血（无视格挡），然后减少 1 层。
- 战斗胜利获得金币、三选一卡牌奖励，初始遗物恢复 4 点生命；也可跳过卡牌奖励。
- 在地图选择下一层相邻节点；第 9 层是首领，击败后通关。生命归零进入失败结算，可重新挑战。
- 营火可恢复 18 点生命或升级一张卡；商店提供卡牌、治疗和移除基础攻击牌；精英战提供四叶草遗物。
- 设置中可导入自己的炸虾尾角色图片（PNG、JPG、WebP，最大 2 MB），头像、战斗和卡面同时替换。自定义图片保存在当前浏览器，也可恢复默认同人插画。
- 浏览器本地自动存档；设置中可以确认重开。存档保存在当前浏览器，不跨设备同步。
- 手机端左右滑动手牌，顶部地图图标打开完整路线。弹窗支持 Escape 关闭与 Tab 导航。

## 内容

- 16 种不同卡牌，支持升级、攻击、格挡、抽牌、治疗、连击、群攻、发霉、受潮、勇气与消耗。
- 3 类普通敌人、精英变体、1 位首领；每种敌人有循环行动意图。
- 9 层分支地图、三类随机事件、商店、营火、战后奖励、通关与失败结算。
- 原创 SVG 占位插画、响应式界面、可切换轻柔音效、牌组与牌堆查看、卡牌图鉴和战斗日志。

## 源码结构

```text
src/game.ts       独立游戏状态、种子随机数、卡牌数据和动作 reducer
src/game.test.ts  规则测试和 20 个随机种子的合法动作旅程模拟
src/App.tsx       React 交互界面、地图、场景、卡牌、弹窗与自动存档
src/art.tsx       炸虾尾同人角色图、原创敌人、森林场景和卡牌插画
src/style.css     奶油色森林手账视觉、手机布局与减少动态效果适配
```

所有游戏动作由纯 reducer 校验后产生新状态。地图、敌人、牌组和随机种子全部保存在单一状态中，刷新不会重抽当前奖励或重置战斗。

## 美术与项目说明

本项目为《角落生物》非官方同人玩法原型。可玩角色明确为 San-X 角色炸虾尾（えびふらいのしっぽ），角色图片为按原角色特征重新绘制的同人插画，场景和敌人为原创占位插画，没有直接复制或打包官方图片和音效。角色设定参考：https://www.san-x.co.jp/sumikko/profile/ 。图标来自 lucide-react（ISC 许可），其余依赖保留各自许可证。首版聚焦一名角色和完整的单章体验，后续可扩展章节、角色和卡池。
